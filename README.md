# ChurnDashboard_L

A dashboard for analyzing and visualizing customer churn.

## Overview

ChurnDashboard_L helps track, analyze, and visualize customer churn metrics to support retention decisions.

## Features

- Churn rate tracking over time
- Customer segmentation and cohort analysis
- Key retention/churn indicators at a glance
